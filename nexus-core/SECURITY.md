# Security Policy

## Scope

NORDIC NEXUS Core is an early-stage educational engineering project. Do not submit real credentials, customer data, production inventories or sensitive infrastructure details in issues.

## Reporting

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer privately through a verified channel. Do not publish exploit details for an unresolved issue.

## Safe use

The current evaluator processes local JSON only. It does not authenticate to cloud providers, inspect live accounts or certify compliance. Review all code and generated findings before operational use.
